# Smart Dashboard

Панель для Яндекс Браузера: погода, курсы валют и калькулятор.

Яндекс Браузер поддерживает Manifest V3, `chrome.storage` и `chrome.alarms`, но не поддерживает боковую панель `chrome.sidePanel`. Поэтому расширение открывается всплывающим окном по иконке. Кнопка «Открыть во вкладке» оставляет ту же панель открытой рядом с другими вкладками. Ключ `side_panel` в манифест не добавлен: незнакомое разрешение может помешать установке.

## Установка в Яндекс Браузер

1. Распакуйте архив `smart-dashboard.zip`, если скачали его. Внутри должна быть папка с `manifest.json`.
2. Откройте `browser://extensions`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите папку `smart-dashboard`.
5. Закрепите Smart Dashboard на панели браузера и нажмите иконку.

Настройки открываются шестерёнкой в шапке панели. Город, тема, избранные валюты, сумма и последний расчёт сохраняются в `chrome.storage.local`.

## Откуда берутся данные

- Погода и поиск города: [Open-Meteo](https://open-meteo.com/) и [Geocoding API](https://geocoding-api.open-meteo.com/).
- Название города по координатам: BigDataCloud. У Open-Meteo есть поиск по названию, но нет обратного геокодинга.
- Курсы: [Frankfurter](https://api.frankfurter.dev/) v2, без ключа. В ответе есть RUB, USD, EUR, GBP, CHF, CNY, PLN и остальные валюты с кодом ISO.

Погода в фоне обновляется каждые 15 минут, курсы — каждый час. Интервал меняется в настройках. Если сеть пропала, панель показывает последний успешный ответ и пишет об этом.

Калькулятор считает выражение сам, без `eval()`. Процент после сложения и вычитания считается от левой части: `100+10%` даёт 110, `200-10%` даёт 180. В остальных случаях `10%` — это 0,1, поэтому `50*10%` даёт 5.

## Как проверить

### Погода

1. Откройте панель и введите «Москва». В подсказках выберите Москва, Россия.
2. Должны появиться температура, ощущаемая температура, влажность, ветер, условия и прогноз на 7 дней.
3. Нажмите кнопку определения города и разрешите геолокацию. Город и прогноз сменятся.
4. Отключите сеть и нажмите обновление. Останутся последние данные и сообщение об ошибке.

### Курсы

1. Оставьте сумму 1000, базовую валюту RUB и целевую USD.
2. Результат, строка «1 RUB = … USD» и дата курса должны прийти с сервера, а не из зашитых чисел.
3. Поменяйте валюты кнопкой ⇄ и проверьте избранные валюты под конвертером.
4. Введите `abc` в сумму: появится сообщение «Введите корректную сумму».

### Калькулятор

1. Наберите `100+10%` и нажмите `=`. Результат: 110.
2. Проверьте `(2+3)*4` = 20, `5/0` показывает «Деление на ноль».
3. Нажмите ⌫, C, скобки и проценты. Те же клавиши работают с клавиатуры, когда курсор не в поле поиска или суммы.
4. Скопируйте результат и откройте «История вычислений». Повторный щелчок по строке возвращает пример.

### Настройки

1. Переключите светлую тему, °F и м/с. Панель должна запомнить выбор после закрытия.
2. Измените интервал обновления и список избранных валют.
3. Сбросьте кэш и историю. После сброса данные снова загрузятся из API.


### Установка

browser://extensions → режим разработчика → «Загрузить распакованное расширение» → папка smart-dashboard.
